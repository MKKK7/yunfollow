# 云追实施与验收清单

## 已授权范围

只使用115原生转存或115云端离线；不在NAS下载视频再上传。复用现有盘搜、LitePan、OpenList、Emby；保留数据、许可证和回退版本。仓库及产品改名YunFollow／云追。

## 功能验收

- 命名移除TMDBID；内部身份和NFO继续保存ID。
- 先分电影／剧集，再优先动漫、综艺，最后地区；未知分类进入115待分类。
- 通过网页或Bot选择分类，115云端移动后继续STRM和刮削。
- 候选每批最多3个；实际文件、清晰度、字幕、编码、音轨、大小、来源、缺集与逐集清单均可查看。
- 链接失效、电影误匹配、预告和重复候选排除。超时与失效分开；选择前再次核验。
- 下一批只忽略当前批次；忽略状态持久化，仍持续订阅。
- 确认首个资源后按偏好自动补缺集；已播与未播分开，不承诺不存在的资源一定找到。
- 任务详情展示全部14个阶段；服务、时间、回执、错误、逐文件回写进度和失败阶段重试。
- 独立来源管理页面：名称、备注、类型、链接、启停、扫描间隔、测试读取、立即同步。
- 服务状态页区分配置和实际接口可用，展示调用关系。无需Docker socket。
- Bot支持卡片确认、忽略、下一批、目录选择和重试，普通交流经意图校验。
- 磁力／电驴只发送115云端离线；草稿、确认、提交未知、下载中、失败、文件确认分别持久化。
- 资料回写SHA256读回；Emby刷新接受与实际已索引分开。

## 部署验收

先跑单元和浏览器交互测试，再在Linux容器运行完整上游回归。迁移前停止旧服务并备份数据库、配置、CLI授权；不能同时运行两个Bot轮询器。使用新目录`AppData/YunFollow`和新容器名`yunfollow`，保留旧数据供回退。

真实验收以现有订阅《胆大党》补集与联动为主。不存在合格补集来源时保持等待；未知字幕和分辨率的版本交给用户选择，不偷偷降低偏好。离线真实资源单独记录115返回结果，不用模拟结果冒充。

已完成目录若仍带旧ID，迁移时必须核对115文件ID、原目标目录及STRM引用。命名模板变化不代表既有目录已迁移。
